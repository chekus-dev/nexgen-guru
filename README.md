## 🌟 Overview

**NexGen Guru Consulting** is a **Digital Education and Creative Technology** company based in Makurdi, Nigeria. We prepare young people for opportunities created by AI, digital media, and the creative economy through **practical, project-based training** — not just theory.

This repository contains the **complete source code** for our website: a modern, fully responsive platform built with **Go**, **PostgreSQL (Supabase)**, and **Tailwind CSS**.

- ✅ PostgreSQL integration via `pgx`

- ✅ Graceful error handling
